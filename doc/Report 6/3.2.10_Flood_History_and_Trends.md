# 3.2.10 Flood History and Trends

This section describes how to use the **Flood History and Trends** module in the FDA System. The module provides two main capabilities:

- **View Flood History** – Inspect historical water level readings (short-hour presets) for a selected monitoring station.
- **Flood Trends** – Analyze aggregated flood patterns over longer periods through different chart views (area chart, bar chart, heatmap).

---

## 3.2.10.1 View Flood History

This feature allows authorized users (Admin, Moderator) to view historical water level readings for a selected station in short time windows (hours). The screen includes a station list panel (left), KPI summary cards (top-right), and a line chart that renders the historical readings.

### Step 1: Navigate to the Flood History Module

From the Admin/Moderator Dashboard, in the left-hand sidebar, click **"Lịch Sử Ngập"**.

The Flood History page is displayed with:

- A **station list** panel on the left
- A **time preset** selector (Khoảng thời gian) on the left
- A **"Làm mới"** button at the top-right of the page header
- A **KPI strip** (4 cards) above the chart area
- A **line chart** in the analysis panel

Figure xx: Flood History – Page Overview

### Step 2: Select a Monitoring Station

In the left panel, under **"Danh sách trạm"**, click one station item to select it.

Each station row shows:

- Station name and station code
- Optional location description
- Data quality (percentage), when available
- Status badge such as **"Hoạt động"**, **"Mất kết nối"**, or **"Bảo trì"**

After selection, the station row is highlighted, and the page automatically loads data for the selected station.

Figure xx: Flood History – Select Station from List

### Step 3: Choose a Short-hour Preset

In the left panel, under **"Khoảng thời gian"**, open the preset dropdown and select one of the short-hour presets:

- **6 giờ gần nhất**
- **12 giờ gần nhất**
- **24 giờ gần nhất**

These presets correspond to the Flood History view (hourly series).

Figure xx: Flood History – Select Short-hour Preset

### Step 4: Refresh Data

Click the **"Làm mới"** button to reload the chart and KPI values for the current selection.

Figure xx: Flood History – Refresh Button Location

### Step 5: Review KPI Summary Cards

Above the chart area, a KPI strip displays 4 summary cards:

- **Mực max**: Maximum water level within the selected time window (unit: cm)
- **Mực TB**: Average water level (unit: cm)
- **Giờ ngập**: Total flood hours (unit: h)
- **Chất lượng**: Data completeness percentage (unit: %)

If KPI data is not available for the current selection, the values are shown as **"—"**.

Figure xx: Flood History – KPI Strip

### Step 6: View the Historical Readings Line Chart

In the analysis panel, a line chart titled **"Phân tích ngập"** displays historical readings for the selected station:

- **X-axis**: timestamps formatted by date and time
- **Y-axis**: water level in centimeters (cm)
- **Tooltip**: hover to see the exact reading value and time; when available, the tooltip also shows severity and quality flag details

Figure xx: Flood History – Line Chart (Hourly History)

### Step 7: Read Missing-data Warnings (if available)

If there are gaps in the readings timeline, a warning box appears below the chart indicating missing intervals:

- Header text: **"Thiếu dữ liệu (N)"** where \(N\) is the number of detected gaps
- A short note indicating shorter time windows often have better coverage
- A list of missing intervals (start → end, duration in minutes)

## 3.2.10.2 Flood Trends

This feature provides aggregated trend analysis over longer periods (days/months/year). The same page is used; changing the time preset automatically switches the chart style and data aggregation level.

### Step 1: Navigate to the Flood History Module

From the Admin/Moderator Dashboard, in the left-hand sidebar, click **"Lịch Sử Ngập"** to open the Flood History page.

Figure xx: Flood Trends – Entry Point (Same Page)

### Step 2: Select a Monitoring Station

In the left panel, click one station in **"Danh sách trạm"** to set the station context for the trend charts.

Figure xx: Flood Trends – Select Station

### Step 3: Choose a Trend Preset (7/30/90/365 Days)

Open the **"Khoảng thời gian"** dropdown and select one of the trend presets:

- **7 ngày**
- **30 ngày**
- **90 ngày**
- **365 ngày**

Click **"Làm mới"** to ensure the latest data is loaded.

Figure xx: Flood Trends – Select Trend Preset

### Step 4: Understand Chart Switching by Preset

Depending on the selected preset, the analysis panel switches to the corresponding trend visualization:

#### 4.1 Preset: 7 Days

The page renders an **area/line trend chart** (trend analysis view) based on aggregated values per period.

Expected chart behavior:

- The chart card title remains **"Phân tích ngập"**
- X-axis shows period labels by date
- The plotted series represents aggregated water-level trends (e.g., average levels by period)

Figure xx: Flood Trends – 7 Days (Area Trend Chart)

#### 4.2 Preset: 30 Days

The page renders a **bar chart** that summarizes water level by day.

Expected chart behavior:

- Bars represent aggregated metrics such as max and average water level per day
- Hovering shows the value in cm and includes flood-hours detail when present in the dataset

Figure xx: Flood Trends – 30 Days (Bar Chart)

#### 4.3 Preset: 90 Days

The page renders an **area/line trend chart** (trend analysis view) over a longer period window.

Figure xx: Flood Trends – 90 Days (Area Trend Chart)

#### 4.4 Preset: 365 Days

The page renders a **heatmap** labeled **"Mẫu ngập theo năm"** to visualize yearly patterns.

Expected heatmap behavior:

- Each day is represented as a cell in a week-by-week grid (T2…CN)
- Cell intensity reflects flood intensity (based on flood hours for that day)
- Hovering a cell shows a detail panel with date, flood duration (hours), and max level (cm)

Figure xx: Flood Trends – 365 Days (Annual Heatmap)

### Step 5: Interpretation and Scope

The Flood Trends views in this module are **aggregations derived from historical data**. They support:

- Recognizing recurring flood patterns
- Comparing periods at a high level
- Summarizing severity over longer time windows

This module **does not** perform AI-based future prediction. It only visualizes trends computed from past readings.
