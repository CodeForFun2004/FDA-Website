# 3.2.5 Alert and Notification Management

This module allows authorized users to manage alert message templates and publish notifications/news to end users. In the current web UI, **Moderator** users access these functions under the sidebar group **"Cảnh Báo & Tin"**.

---

## 3.2.5.1 Alert Message Template Management

This feature allows users to create, preview, edit, and delete predefined alert templates. Templates are used as standardized message bodies for flood-related alerts.

### Step 1: Open the Alert Template Page

From the dashboard sidebar, expand **"Cảnh Báo & Tin"** and click **"Mẫu Cảnh Báo"**.

The page **"Mẫu Cảnh Báo"** displays a table of existing templates and an action to add a new template.

Figure xx: Alert Template Management – Templates Table

### Step 2: Create a New Template

Click the **"Add" / "Tạo"** action on the page (create button in the templates view).

A form dialog opens to enter the template information (name, condition fields if available, and message body).

Click **Save** to create the template.

Figure xx: Alert Template Management – Create Template Dialog

### Step 3: Preview, Edit, or Delete a Template

In the templates table, open the row actions menu (action button per template).

Available actions typically include:

- **Preview**: open the preview dialog to inspect the rendered template content.
- **Edit**: update template fields, then save changes.
- **Delete**: remove the template (confirmation may be required).

Figure xx: Alert Template Management – Row Actions (Preview / Edit / Delete)

## 3.2.5.2 Send and Management Notification (Moderator – "Tin Tức")

This feature allows Moderator users to create and publish notifications/news to users. Notifications are managed in the **"Tin Tức"** page, where items can be drafted, scheduled, published, edited, and deleted.

### Step 1: Open the News / Notification Page

From the dashboard sidebar, expand **"Cảnh Báo & Tin"** and click **"Tin Tức"**.

The page **"Tin Tức"** displays a listing table of announcements/notifications.

Figure xx: News – Listing Table (Tin Tức)

### Step 2: Create a New Notification

Click **"Tạo Bản Tin"** (top-right).

A dialog titled **"Tạo thông báo"** opens. Fill in the required fields:

- **Tiêu đề** (required)
- **Nội dung** (required)
- Optional: **Tóm tắt**, **Hình ảnh đại diện** (URL or Upload), **Đối tượng nhận** (Tất cả / Theo khu vực / Theo vai trò), **Độ ưu tiên** (Thấp/Bình thường/Cao/Khẩn cấp)
- Optional scheduling: enable **"Đặt lịch đăng"** and select a future date/time

Click **"Tạo thông báo"** to save.

Figure xx: News – Create Notification Dialog (Tạo thông báo)

### Step 3: Publish (Send) a Notification

In the listing table, open the row action menu (**"Thao tác"**).

If the item is in **draft/pending** status, click **"Đăng ngay"** to publish.

After publishing, a toast message appears: **"Đã đăng thông báo"**.

Figure xx: News – Publish Action (Đăng ngay)

### Step 4: View, Edit, or Delete a Notification

In the same row action menu (**"Thao tác"**):

- Click **"Xem chi tiết"** to open the details dialog.
- Click **"Sửa"** to edit (only available for draft/pending items).
- Click **"Xóa"** to remove the notification (a confirmation modal appears).

Figure xx: News – View / Edit / Delete Actions
