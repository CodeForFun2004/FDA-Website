# 3.2.7 Flood Map (Real-time)

This section describes how authorized users (Admin, Moderator) use the interactive map to monitor real-time flood conditions, inspect station sensor readings, and control map layers (including community reports).

---

## 3.2.7.1 View Real-time Flood Map

This feature provides a full-screen, interactive map view for real-time monitoring. The map displays monitoring stations as colored circular markers and includes a flood severity legend (**"Mức độ ngập"**) at the bottom-left.

### Step 1: Open the Map Interface

From the dashboard side menu, select **"Bản Đồ & Vùng"**.

The system loads a full-screen interactive map centered on the monitored city/region.

Figure 87: Real-time Flood Map – Overview (Bản Đồ & Vùng)

### Step 2: Understand the Flood Severity Legend

At the bottom-left corner of the map, locate the legend panel labeled **"Mức độ ngập"**.

This panel indicates flood severity levels and the corresponding visual colors shown on the map.

Use the legend to interpret marker colors at a glance:

- **Green (safe)**: **An toàn** – Safe / normal water level
- **Yellow (caution)**: **Cảnh giác** – Elevated water level (early risk)
- **Orange (warning)**: **Cảnh báo** – High water level (warning range)
- **Red (critical)**: **Nghiêm trọng** – Critical flooding level (highest risk)

Figure 88: Flood Severity Legend – “Mức độ ngập”

### Step 3: Interpret Real-time Station Markers

On the map, monitoring stations appear as colored circular markers. These markers represent the latest observed condition (real-time snapshot) for each station.

Users can visually scan the map to identify areas of higher concern and then click on specific markers for details.

---

## 3.2.7.2 Monitor Station Sensor Data

This feature allows users to open a station detail card directly from the map and read live metrics (e.g., current water level and last update time).

### Step 1: Select a Specific Station on the Map

On the map, locate the colored station markers representing monitoring stations.

Click on any station marker to open a station detail card.

Figure 99: Station Sensor Details – Station Card on Map

### Step 2: Read Live Metrics

In the station detail card (left side), review the station’s real-time information, including:

- **Station header**: station name (e.g., **"Trạm Giám Sát Đường Lê Văn Hiến"**) and a short location line below it.
- **Status badge**: a small badge such as **"SAFE"** displayed near the top metrics area.
- **Current water level**: labeled **"Mực nước"**, shown in meters (example: **1.1 m**).
- **Supporting metrics**: two compact values shown below (as in the UI), for example:
  - **"Mực max"** (example: **150 cm**)
  - **"Chỉ số"** (example: **148.9 cm**)
- **Last update time**: labeled **"Cập nhật:"** followed by a timestamp (HH:mm:ss).

### Step 3: Navigate from the Station Card (if available)

If the station card includes a navigation button (e.g., **"Xem trạm"**), click it to open the station detail page for deeper inspection.

---

## 3.2.7.3 Filter Map Layers and Data

This feature allows users to control which datasets are visible on the map through the layer panel (**"Lớp Bản Đồ"**). Users can also switch the base map type.

### Step 1: Access the Layer Panel

On the map view, locate the layer panel button at the top-right corner (map control area).

Click the button to open the panel titled **"Lớp Bản Đồ"**.

Figure 100: Map Layer Panel – “Lớp Bản Đồ”

### Step 2: Switch Base Map Type

Inside **"Lớp Bản Đồ"**, use the **"Loại nền"** controls to switch between base map styles:

- **"Tiêu chuẩn"** (standard road map)
- **"Vệ tinh"** (satellite view), if available

After selecting, click **"Lưu"** to apply changes.

Figure 101: Base Map Switch – “Loại nền”

### Step 3: Toggle Data Layers (Stations, Administrative Areas, Community Reports)

In the same panel, locate the **"Chế độ Khu Vực"** and other layer toggles.

These controls allow you to show/hide different datasets, such as:

- Administrative areas (e.g., **"Khu Vực Admin"**)
- Monitoring stations (e.g., **"Trạm Quan Trắc"**)
- Community reports (e.g., **"Báo Cáo Cộng Đồng"**) for real-time citizen-submitted reports

After making changes, click **"Lưu"**.

Figure 102: Layer Toggles – Admin Areas, Stations, Community Reports

### Step 4: View Community Reports in Real-time (On Map)

When the **"Báo Cáo Cộng Đồng"** layer is enabled:

1. Community report markers become visible on the map alongside station markers.
2. Click a community report marker to open the report detail popup card.

The popup card (left side) is titled **"Phản ánh cộng đồng"** and typically includes:

- **Report content**: a short description (example text shown directly under the title).
- **Key fields** displayed as short label/value rows (depending on report data), such as:
  - **"Mức độ"** (severity)
  - **"Tin cậy"** (trust / confidence indicator)
  - **"Trạng thái"** (status)
- **Timestamp**: displayed on the card as a date/time line.
