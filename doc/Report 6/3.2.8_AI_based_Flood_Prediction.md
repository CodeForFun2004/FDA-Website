# 3.2.8 AI-based Flood Prediction

This section describes how to use the AI-powered flood prediction feature in the FDA System. The feature consists of three main capabilities:

- **View AI-based Flood Prediction** – Run an AI analysis for a specific administrative area.
- **Compare AI Predictions with Actual Data** – Evaluate prediction accuracy by overlaying AI forecast windows against real-time water level data.
- **Identify High-risk Flood Zones (AI)** – Visually locate areas with the highest flood risk on the map.

---

## 3.2.8.1 View AI-based Flood Prediction

This feature allows authorized users (Admin, Authority, Super Admin) to trigger an AI analysis for any administrative area displayed on the flood map. The system computes a multi-source ensemble prediction and returns flood probability, confidence, estimated impact, and contributing sensor stations.

### Step 1: Navigate to the Flood Map

Log in to the FDA System and access the Admin Dashboard.
In the left-hand sidebar, click **"Zones"** (or **"Flood Map"**, depending on your deployment).
The map view loads, displaying administrative area polygons over a base map layer.

### Step 2: Confirm Required Map Layers are Active

Before running AI prediction, ensure the following layers are enabled via the **Layer Panel**:

- **Khu Vực Admin** – Toggle ON to show administrative area boundaries. Clicking an area triggers the prediction card.
- **Trạm Quan Trắc** – Toggle ON to display sensor station markers. Station data contributes to the AI prediction.

Open the Layer Panel by clicking the Layers button on the map interface. Adjust toggles as needed, then click **Lưu** (Save) to apply changes.

### Step 3: Select an Administrative Area on the Map

Click directly on any administrative area polygon (ward or district boundary) displayed on the map.

The system highlights the selected area by zooming the map camera to fit the area's boundary.
The **Area Detail Card** slides in from the left side of the screen, showing:

- Area name and administrative code
- Two action buttons: **Chụp ảnh vệ tinh** (Satellite) and **Dự đoán AI** (AI Prediction)

### Step 4: Trigger AI Flood Prediction

Click the **Dự đoán AI** button (purple/violet button with a sparkles icon).

The button label changes to **Đang gọi AI…** and becomes disabled while the request is in progress.
The system calls the backend API to assemble data from multiple sources (weather data, satellite imagery, sensor stations, and terrain analysis) and compute the ensemble prediction.

### Step 5: Review the AI Prediction Result

Upon successful completion, the **PredictFloodAiPanel** section expands within the Area Detail Card, displaying:

#### 5.1 Model Result Hero Card (top section, colored background)

| Field | Description |
|---|---|
| **Xác suất lũ** (Flood Probability) | The ensemble model's predicted probability of flood occurrence, expressed as a percentage. |
| **Mức rủi ro** (Risk Level) | The derived risk level based on probability thresholds: Cao (High, >70%), Trung bình (Moderate, 50–70%), Vừa (Medium, 15–50%), Thấp (Low, ≤15%). |
| **Độ tin cậy** (Confidence) | The model's confidence score for this prediction, expressed as a percentage. |

The background color of the hero card reflects the risk level:

- **Green gradient** – Safe / Low risk
- **Yellow gradient** – Caution / Medium risk
- **Orange gradient** – Warning / Moderate risk
- **Red gradient** – Critical / High risk

#### 5.2 Estimated Accuracy by Model Phase

Below the hero card, a section titled **Độ chính xác ước tính (theo giai đoạn mô hình)** shows the accuracy of each ensemble component:

| Phase | Source | Description |
|---|---|---|
| baseline_accuracy | WeatherAPI | Baseline weather forecast accuracy |
| phase_1_accuracy | Open-Meteo | Regional weather accuracy by coordinates |
| phase_2_accuracy | Copernicus | Soil saturation / water absorption data |
| phase_3_accuracy | DEM | Terrain slope, drainage, flood risk mapping |
| total_improvement | Full Stack | Combined accuracy across all signal sources |

#### 5.3 Impact Estimation (white card below hero)

| Field | Description |
|---|---|
| **Độ sâu nước ước tính** | Estimated flood water depth in meters |
| **Phạm vi ảnh hưởng ước tính** | Estimated area affected by the predicted flood |
| **Khuyến nghị** | AI-generated recommended action, displayed in a color-matched recommendation box |

#### 5.4 Area Status Summary

A compact bar below the hero card shows:

- **Trạng thái khu vực:** [status label] – e.g., NORMAL, CAUTION, WARNING, CRITICAL
- Severity level badge (mức 1–4) if applicable

#### 5.5 Administrative Area Information

A card titled **Khu vực đánh giá** shows the name, code, and parent area of the selected district/ward.

#### 5.6 Forecast Windows – Time-based Predictions

A section titled **Xu hướng theo khung giờ** displays prediction chips for multiple forecast horizons (e.g., +1h, +3h, +5h, +7h). Each chip shows:

- Forecast time label
- Flood probability percentage
- Status (e.g., NORMAL, WARNING, CRITICAL)

Chips are color-coded according to the FLOOD_TIER_UI system (green/yellow/orange/red). This provides a forward-looking view of how the flood risk evolves over the next several hours.

#### 5.7 Monitoring Stations Near the Area

A collapsible section titled **Trạm đo gần khu vực** (expandable by clicking) lists all sensor stations contributing data to the prediction. Each entry shows:

- Station code and name
- Current water level in meters
- Severity badge (Nghiêm trọng / Cao / Trung bình / Thấp / Bình thường)
- Street and ward location

#### 5.8 Community Reports

A collapsible section titled **Phản ánh từ người dân** (expandable by clicking) lists citizen-submitted flood reports within the area. Each entry shows:

- Report description
- Severity level badge
- Timestamp (formatted as DD/MM/YYYY, HH:mm in Vietnamese locale)

#### 5.9 AI Analysis & Recommendation

A section titled **Phân tích & khuyến nghị (AI)** displays the AI consultant's full summary text in a recommendation box.

#### 5.10 Technical Details (expandable)

A collapsible **Chi tiết kỹ thuật (thời tiết, đất, địa hình…)** section shows raw technical components (weather, saturation, terrain, historical similarity) as expandable JSON previews for advanced users.

### Step 6: Handle Errors and Mismatches

If the API call fails, an error banner appears below the action buttons inside the Area Detail Card:

- **Vệ tinh error** – Red banner with alert icon showing the error message
- **Dự đoán AI error** – Amber/yellow banner with alert icon showing the error message

If the returned area does not match the selected area on the map, a warning line appears:

- **Phản hồi dự đoán AI không khớp khu vực đang chọn trên bản đồ.** (AI prediction response does not match the currently selected area on the map.)

### Step 7: Close the Area Detail Card

Click the **×** button at the top-right corner of the Area Detail Card to close it and deselect the area on the map.
Alternatively, click anywhere on the map background to deselect.

## 3.2.8.2 Compare AI Predictions with Actual Data

This feature enables authorized users to evaluate the accuracy of AI flood predictions by comparing the predicted forecast windows against real-time water level data from sensor stations. The comparison is facilitated through the **Flood History** module.

### Step 1: Navigate to the Flood History Module

From the Admin Dashboard sidebar, click **"Flood History"** or **"Lịch Sử Ngập"**.

The Flood History page loads with:

- **Filter Bar** on the left (sticky)
- **KPI Cards** row below the filter bar
- **Chart Area** displaying trend or bar charts

### Step 2: Open the Filter Panel

The **Flood Filter Bar** is expanded by default. If collapsed, click the filter panel header to expand it.

### Step 3: Select Station(s) for Comparison

The filter bar supports two modes for comparison:

#### Single Station Mode (default)

Use the **Station** dropdown to select one monitoring station.
Select **Trend Analysis** as the View Mode.

#### Compare Mode (multi-station)

Toggle the **Compare Mode** switch to enable multi-station selection.
The dropdown changes to a list of clickable station buttons.
Select up to **3 stations** by clicking each station button. Selected stations display a checkmark.

Comparison mode switches the view to **Detailed History** automatically.

### Step 4: Choose a Time Period

In the **Period** dropdown, select one of the following presets:

- Last 24 Hours
- Last 7 Days
- Last 30 Days
- Last 90 Days
- Last 365 Days

Select a period that aligns with the AI prediction window you want to evaluate (e.g., select "Last 7 Days" to compare against a 5-hour or 7-hour AI forecast).

### Step 5: Apply the Filters

Click the **Apply Filters** button (or the filter icon button).

The system fetches historical water level data for the selected station(s) and time period.
The chart area updates to display the data.

### Step 6: View the Comparison Chart

After applying filters, the main chart area displays:

#### Trend Analysis View (single station)

A line/area chart titled **"Phân tích ngập"** (Flood Analysis) shows:

- X-axis: Time periods (e.g., days or hours depending on the selected period and granularity)
- Y-axis: Water level in centimeters (cm)
- Primary line: **Mực nước TB** (Average Water Level) – the actual observed data
- Secondary line: **Mực nước max** (Maximum Water Level) – the peak observed level
- Flood hours indicator in tooltip

A comparison footer section (card footer) shows comparison badges relative to the previous period:

- **Mực TB:** ±X% – average water level change vs previous period
- **Giờ ngập:** ±X% – flood hours change vs previous period

Green badge indicates improvement; red badge indicates worsening.

#### Detailed History View (compare mode or detailed view)

A bar chart titled **"Phân tích ngập"** displays:

- Grouped bars per time period (e.g., per day)
- Each group shows **Mực max** (Maximum, red/destructive color) and **Mực TB** (Average, primary color)
- Hover over a bar to see the exact value and flood hours for that period

The chart tooltip indicates: `[value] cm · [X]h ngập`

### Step 7: Interpret the Comparison with AI Forecast Windows

To evaluate AI prediction accuracy against actual data:

1. Identify the time horizon of interest in the AI prediction (e.g., +3h, +5h, +7h forecast window from section 3.2.8.1, Step 5.6).
2. In the Flood History chart, locate the corresponding time point or period.
3. Compare:
   - **AI Forecast Probability** (from PredictFloodAiPanel) vs **Actual Flood Hours** (from chart)
   - **AI Risk Level** (Cao / Trung bình / Vừa / Thấp) vs **Actual Max Water Level** (cm)
4. A forecast window with high probability (e.g., >70%) that corresponds to a period with high actual flood hours in the chart indicates accurate prediction.
5. Divergence between predicted risk and actual data may indicate model drift or need for re-calibration.

### Step 8: Log Prediction Records

To maintain a training dataset for future model improvement:

1. After reviewing each comparison, record the following in an external log or documentation:
   - Administrative area name
   - Forecast timestamp
   - AI predicted probability and risk level
   - Actual observed water level (from chart)
   - Actual flood hours
   - Deviation (difference between predicted and actual)

This data supports model retraining and accuracy improvement over time.

### Step 9: View KPI Summary

Above the chart, **KPI Cards** provide a quick statistical summary for the selected period:

| KPI | Metric | Description |
|---|---|---|
| **Max Water Level** | [X] cm | Highest water level recorded in the selected period |
| **Avg Water Level** | [X] cm | Average water level across the period |
| **Total Flood Hours** | [X]h | Total hours where water level exceeded the warning threshold |
| **Data Completeness** | [X]% | Percentage of expected data points that were recorded |

Trend badges on each card show the change vs the previous equivalent period (e.g., +15% vs previous period).

## 3.2.8.3 Identify High-risk Flood Zones (AI)

This feature highlights areas with the highest flood risk on the interactive map using AI-driven probability data, enabling authorities to prioritize response and mitigation efforts.

### Step 1: Navigate to the Zones / Flood Map

From the Admin Dashboard, click **"Zones"** in the sidebar.
The interactive map view loads with administrative area boundaries and sensor station markers.

### Step 2: Enable the Flood Severity Layer

Open the **Layer Panel**.
Toggle **Trạm Quan Trắc** to ON to activate the flood severity overlay.
Click **Lưu** (Save) to apply the change.

The map now displays:

- **Sensor station markers** colored by current severity level:
  - **Green** (#16A34A) – Safe (< 10 cm above sensor threshold)
  - **Yellow** (#CA8A04) – Caution (10–20 cm)
  - **Orange** (#EA580C) – Warning (20–40 cm)
  - **Red** (#DC2626) – Critical (≥ 40 cm)
- **Critical radius rings** – Large pulsing red circles around stations with Critical severity, indicating high-risk zones on the map

### Step 3: Reference the Flood Legend

The **Mức độ ngập** (Flood Severity) legend appears in the bottom-left corner of the map when the station layer is active. It displays:

| Level | Label | Color |
|---|---|---|
| Safe | An toàn (< 10 cm) | Green |
| Caution | Cảnh giác (10–20 cm) | Yellow |
| Warning | Cảnh báo (20–40 cm) | Orange |
| Critical | Nghiêm trọng (≥ 40 cm) | Red (pulsing) |

### Step 4: Identify High-risk Zones via AI Prediction

For each administrative area on the map:

1. **Click the area polygon** to open the **Area Detail Card**.
2. **Click "Dự đoán AI"** to run the AI prediction (as described in section 3.2.8.1).
3. **Read the risk level from the hero card**:
   - **Cao** (red gradient hero) – Highest risk. All stations in the area show Critical or Warning status. Immediate attention required.
   - **Trung bình** (orange gradient hero) – Moderate risk. Stations show Warning or Caution status.
   - **Vừa** (yellow gradient hero) – Medium risk.
   - **Thấp** (green gradient hero) – Low risk.

4. **Check the Forecast Windows section** (Xu hướng theo khung giờ) to see how risk evolves over the next 3–7 hours. Windows with Critical status indicate time-specific high-risk periods.

5. **Check the Contributing Stations section** to identify which specific stations are driving the high-risk assessment. These are the stations with the most significant water level readings.

### Step 5: Locate Critical Zones on the Map

High-risk zones are visually identifiable on the map through the following indicators:

- **Red pulsing markers** (critical stations) – Large, animated red dots with a pulsing outer ring on the map at critical station locations.
- **Red gradient hero cards** in the Area Detail Card – When an area's AI prediction shows Critical risk, the entire result panel uses a red gradient background for immediate visual recognition.
- **Window chips colored red** in the forecast timeline – Specific hours marked as CRITICAL are shown in red chips.

To quickly find the highest-risk zones across the map:

1. Toggle **Trạm Quan Trắc** layer ON.
2. Visually scan the map for red pulsing markers.
3. Click each red marker to open the **Flood Detail Card** for that station, showing:
   - Station name and location
   - Current water level in cm
   - Alert level (CRITICAL / WARNING / CAUTION / SAFE)
   - Sensor height and distance
   - Last update timestamp
   - **"Xem trạm"** button to navigate to the full station detail page

### Step 6: Respond to Identified High-risk Zones

Based on the AI-identified high-risk zones, authorities can take the following actions:

| Risk Level | Recommended Action |
|---|---|
| **Critical (Cao)** | Immediate deployment of response teams. Issue alerts to affected residents. Monitor real-time water levels. |
| **Warning (Trung bình)** | Pre-position resources. Issue advisory notices. Continue monitoring. |
| **Caution (Vừa)** | Enhanced monitoring. Prepare contingency plans. |
| **Safe (Thấp)** | Normal operations. Continue routine monitoring. |

### Step 7: Overlay Satellite Analysis (Optional)

For enhanced situational awareness, authorities can overlay satellite flood analysis on top of the station layer:

1. Click an administrative area polygon to open the **Area Detail Card**.
2. Click **"Chụp ảnh vệ tinh"** (Satellite Analysis button).
3. The label changes to **"Đang phân tích…"** while the API call is in progress.
4. Upon success, satellite-derived flood anomaly polygons are overlaid on the map within the selected area.
5. The area boundary is highlighted on the map, and the satellite analysis status is reflected in the Area Detail Card.

This provides a visual confirmation of actual flood extent, complementing the AI prediction and station data.
