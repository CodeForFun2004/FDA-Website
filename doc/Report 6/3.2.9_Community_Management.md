# 3.2.9 Community Management

This section describes how Moderator users manage community-submitted flood reports in the FDA System. The module supports two main capabilities:

- **View Community Flood Report** – View, filter, and inspect community flood reports (including attached media).
- **Hide Invalid Report** – Hide reports that are invalid, duplicated, or not suitable for display.

---

## 3.2.9.1 View Community Flood Report

This feature allows Moderator users to review flood reports submitted by citizens. Reports can be filtered by status, severity, trust score, and date range. Each report item provides location details, report content, reporter information, and media preview.

### Step 1: Navigate to Community Management

Log in as a **Moderator**.

From the left-hand sidebar, click **"Cộng Đồng"**.

The page **"Phản ánh cộng đồng"** is displayed with:

- A quick status switch area (**Lọc nhanh theo trạng thái**) at the top
- A filter form (**Bộ lọc phản ánh cộng đồng**)
- A report list section (**Danh sách phản ánh**)
- Pagination controls at the bottom

Figure xx: Community Management – Page Overview

### Step 2: Use Quick Filter Tabs (Status)

At the top of the page, use the quick tabs under **"Lọc nhanh theo trạng thái"**:

- **Tất cả**
- **Đang hiển thị**
- **Đã ẩn**

Selecting a tab immediately changes the status filter and refreshes the report list.

Figure xx: Community Management – Quick Status Tabs

### Step 3: Configure Detailed Filters

In the **"Bộ lọc phản ánh cộng đồng"** section, configure optional filters:

- **Trạng thái**: Tất cả / Đang hiển thị / Đã ẩn
- **Mức độ**: Tất cả / Thấp / Trung bình / Cao
- **Điểm tin cậy tối thiểu**: numeric value (example: 1)
- **Từ ngày**: start date (date input)
- **Đến ngày**: end date (date input)

Figure xx: Community Management – Filter Panel

### Step 4: Reload or Clear Filters

Below the filter inputs:

- Click **"Tải lại"** to fetch the report list using the current filters.
- Click **"Xóa bộ lọc"** to reset all filters back to default values.

Figure xx: Community Management – Reload and Clear Filter Buttons

### Step 5: Review the Report List

In the **"Danh sách phản ánh"** section:

- The header shows total report count: **"Tổng cộng [N] bài phản ánh."**
- A page badge shows the current page: **"Trang [current]/[total]"**

Each report item typically contains:

- A preview image/video area (left)
  - Button **"Xem lớn"** opens the media preview dialog
  - Thumbnails appear if multiple media files are attached
- Metadata badges (right)
  - **Mức độ:** Thấp / Trung bình / Cao
  - **Trạng thái:** Đang hiển thị / Đã ẩn
  - **Điểm tin cậy:** \(trustScore\) (if available)
  - **Điểm:** \(score\) (if available)
- Location block
  - Address (or “Chưa có địa chỉ”)
  - Coordinates: latitude, longitude
  - Submit time: **"Gửi lúc: [dd/MM/yyyy, HH:mm]"**
- Report content block
  - Title: **"Nội dung phản ánh"**
  - Description (or “Không có mô tả.”)
- Reporter information block
  - **Người gửi**: reporter name/email (if available), otherwise “Không rõ”
  - **Mức tin cậy**: confidence level (if available)

Figure xx: Community Management – Report Card Details

### Step 6: Open Media Preview (Image/Video)

To inspect attachments:

1. Click **"Xem lớn"** on the preview area (or click a specific thumbnail).
2. A dialog opens titled **"Xem tệp đính kèm"**.
3. The dialog displays:
   - Video player (if mediaType is video), or
   - Full-size image viewer

Close the dialog to return to the list.

Figure xx: Community Management – Media Preview Dialog

### Step 7: Use Pagination Controls

At the bottom of the page:

- The range label indicates displayed items: **"Hiển thị a-b / N bài."**
- Click **"Trang trước"** or **"Trang sau"** to navigate between pages.

Figure xx: Community Management – Pagination Controls

## 3.2.9.2 Hide Invalid Report

This feature allows Moderator users to hide reports that are invalid, duplicated, or contain unsuitable content. Hidden reports are removed from the “Đang hiển thị” view and become visible under the “Đã ẩn” filter.

### Step 1: Locate a Report to Hide

From **"Danh sách phản ánh"**, identify a report that should be hidden.

Reports can be pre-filtered using:

- Quick tab **"Đang hiển thị"**, or
- Filter field **Trạng thái = Đang hiển thị**

Figure xx: Hide Report – Filter for Published Reports

### Step 2: Click the Hide Action

On the right side of the report card, click the **"Ẩn bài"** button.

If the report is already hidden, the button is disabled and displays **"Đã ẩn"**.

Figure xx: Hide Report – Hide Button Location

### Step 3: Confirm the Hide Operation

A confirmation modal appears:

- Message: **"Bạn có chắc muốn ẩn bài phản ánh này không?"**

Click **"Ẩn bài"** to proceed, or **"Hủy"** to abort.

Figure xx: Hide Report – Confirmation Prompt

### Step 4: Observe Success Feedback

After a successful hide action:

- A toast message appears: **"Đã ẩn bài phản ánh"**
- The report list is refreshed automatically
- While the request is in progress, the button state changes to **"Đang ẩn..."**

Figure xx: Hide Report – Success Toast

### Step 5: Verify the Report is Hidden

To verify:

1. Click the quick tab **"Đã ẩn"** (or set **Trạng thái = Đã ẩn** in filters).
2. Confirm the hidden report appears in the list with the status badge **"Đã ẩn"**.

Figure xx: Hide Report – Verify in Hidden Tab
