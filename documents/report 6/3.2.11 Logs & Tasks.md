3.2.11 Operational Logs and Background Jobs (Logs & Tác Vụ)

This section describes how Admin users monitor operational events (system/sensor/alert/moderation logs) and track background jobs responsible for periodic data processing (e.g., data collection and scheduled pipelines used for AI training/evaluation).

The module is available under the sidebar group: “Logs & Tác Vụ”, with two tabs:
- Logs Hệ Thống → `/admin/operational-logs`
- Tác Vụ → `/admin/tasks`

3.2.11.1 View Operational Logs (Sensors / Alerts / Moderation)

Step 1: Navigate to Operational Logs (Logs Hệ Thống)
- Log in as an Admin / Super Admin (or a role with access to the Admin portal).
- From the left-hand sidebar, expand the group “Logs & Tác Vụ”.
- Click “Logs Hệ Thống”.
- The system navigates to the page `/admin/operational-logs`.

Figure xx: Logs Hệ Thống – Navigation Entry

Step 2: Understand the Operational Logs Table
The page header shows:
- A title: “Logs Hệ Thống”
- A total counter: “Tổng [N] bản ghi”
- Three summary badges showing the number of records by severity level on the current result set:
  - “Thông tin”
  - “Cảnh báo”
  - “Lỗi”

Below the header, the main content is a data table. Each row is one operational log record and typically includes:
- Thời điểm – timestamp (localized as `vi-VN`)
- Mức độ – severity level (Info / Warning / Error)
- Nhóm – category (e.g., `system`, `alert`, `sensor`, `moderation`)
- Sự kiện – action name
- Người dùng – userName or userId (if present)
- Đối tượng – entityType (if present)
- Lỗi – indicates whether an `errorMessage` exists (“Có” / “—”)
- Chi tiết – a one-line truncated summary of `details` (if present)

Figure xx: Logs Hệ Thống – Table Overview

Step 3: Search, Filter, and Sort Logs
Use the table toolbar to quickly locate records:
- Search (Tìm kiếm): type keywords to search within details/error text.
- Time range (Thời điểm): pick a start/end time window.
- Severity (Mức độ): select Info / Warning / Error.
- Category (Nhóm): select the log category (options depend on role; see note below).

Sorting:
- Click the column header to sort by: Thời điểm, Mức độ, Nhóm, or Sự kiện.

Note (Role-based visibility):
- If the logged-in user has the role `AUTHORITY`, the UI hides categories `system` and `moderation` from both:
  - The category filter options, and
  - The displayed rows in the table.
This is an intentional UI restriction to reduce exposure of internal system/moderation logs for authority-level accounts.

Figure xx: Logs Hệ Thống – Toolbar Filters (Search / Time Range / Severity / Category)

Step 4: Open Log Details (Drawer)
To inspect a specific record:
- Click anywhere on a row in the table.
- A right-side drawer titled “Chi tiết nhật ký” opens.

The drawer displays:
1) Thông tin cơ bản
   - Thời điểm
   - Nhóm
   - Sự kiện
   - Mức độ badge (Thông tin / Cảnh báo / Lỗi)
2) Ngữ cảnh
   - User (userName or userId)
   - EntityType / EntityId
   - IP
3) Chi tiết (JSON)
   - A JSON/text block representing the `details` payload
   - A “Copy” button to copy the full JSON/details to clipboard
4) Thông báo lỗi (optional)
   - If `errorMessage` exists, it is shown in a red warning block

Figure xx: Logs Hệ Thống – Log Detail Drawer

Step 5: Export Logs (CSV / JSON)
At the top-right of the page header, two export buttons are available:
- “Xuất CSV”
- “Xuất JSON”

Behavior:
- The exported file respects the active filters (search, time range, severity, category).
- Export is not limited to the current page view; it exports the filtered dataset as provided by the backend export endpoint.

Figure xx: Logs Hệ Thống – Export Buttons (CSV/JSON)

Note:
- Các nút Xuất sẽ tạo file theo bộ lọc bạn đang chọn (thời gian/mức độ/nhóm/từ khóa).
- Chi tiết kỹ thuật (API) được hệ thống xử lý tự động, người dùng không cần thao tác.

3.2.11.2 Compare AI Predictions with Actual Data (via Background Jobs Dashboard)

In the current website implementation, the “Tác Vụ” tab provides an embedded Hangfire dashboard used to monitor and manage background jobs (recurring/scheduled tasks). These jobs typically include:
- Data ingestion and aggregation (sensor data, weather data, etc.)
- Scheduled pipelines that prepare datasets for AI training/evaluation
- Periodic jobs that can support comparing AI predictions with actual observed data (backend-defined)

Step 1: Navigate to Background Jobs (Tác Vụ)
- From the left-hand sidebar, expand “Logs & Tác Vụ”.
- Click “Tác Vụ”.
- The system navigates to `/admin/tasks`.

The page shows:
- Page title: “Tác Vụ”
- Description: “Theo dõi job Hangfire (gom dữ liệu, lịch chạy).”

Figure xx: Tác Vụ – Page Entry

Step 2: View the Embedded Hangfire Dashboard
The main content is an embedded Hangfire dashboard loaded inside an iframe.
- If the dashboard is still loading, a “Đang tải…” overlay is displayed.
- Once loaded, the Hangfire UI becomes interactive within the page.

Figure xx: Tác Vụ – Hangfire Embedded Dashboard

Step 3: Open Hangfire in a New Tab (Recommended)
At the top-right of the page, click “Mở Hangfire”.
- The system opens the Hangfire dashboard URL in a new browser tab.
- This is recommended for better navigation and full dashboard features.

Figure xx: Tác Vụ – “Mở Hangfire” Button

Step 4: Track Jobs Relevant to AI Training and Evaluation
Within Hangfire (actual menu labels may vary by backend configuration), operators typically monitor:
- Recurring Jobs: the schedule for periodic tasks (data collection, training pipelines)
- Succeeded Jobs: completed executions (verify last run time and duration)
- Failed Jobs: failures requiring investigation (view error details and retry policy)

Compare AI Predictions with Actual Data (conceptual mapping):
- The comparison itself is usually performed by backend jobs (not a separate React comparison screen).
- The “Tác Vụ” page is the operator entry point to verify those jobs ran successfully and on schedule.

Figure xx: Tác Vụ – Job Monitoring (Succeeded / Failed / Recurring)

Common issues and handling
- If the iframe cannot load:
  - Check network access to the Hangfire URL.
  - If the system requires permission to view jobs, make sure you are logged in with the correct admin account.
  - Use “Mở Hangfire” to open in a new tab as a workaround.
  - If the issue persists, contact the system administrator to verify the job dashboard configuration.
